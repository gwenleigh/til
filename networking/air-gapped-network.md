# Air-gapped network

<img src="https://upload.wikimedia.org/wikipedia/commons/d/da/Air_gap_network.png" width=800 >

An air gap, air wall, air gapping or disconnected network is a network security measure employed on one or more computers to ensure that a secure computer network is physically isolated from unsecured networks, such as the public Internet or an unsecured local area network. It means a computer or network has no network interface controllers connected to other networks, with a physical or conceptual air gap.

- No network connections exist between the secured system and external networks.
- Data transfer is usually done manually, using physical media like USB drives, CDs, or DVDs.

Air-gapped systems are commonly used in environments where security is critical, such as military systems, financial institutions, or industrial control systems. Because the system is physically isolated, hacking or cyber threats from the outside are minimized, but the downside is limited connectivity and difficulty in updating or sharing data securely.
