# Subnetting

Practice problems: 

1) Calculate the IP range for 245.171.16.0/20.

- Network address: 245.171.16.0
- Subnet mask: 255.255.240.0 (or /20 in CIDR notation)
    - Total number of IP addresses: 4,096 (including the network and broadcast addresses)
- Usable IP range: 245.171.16.1 to 245.171.31.254
- The first usable IP is 245.171.16.1, and the last usable IP is 245.171.31.254, with 245.171.31.255 being the broadcast address.
