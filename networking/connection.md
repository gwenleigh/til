# Connection

### Q. What is connection, really?
Does one connection represent one packet sent? Or can one connection send and receive multiple packets?

In networking and packet analysis, a "connection" typically represents a <mark style="background-color:#fadadd">**communication session** between two endpoints (e.g., two computers) over a network.</mark> This session is usually defined by a combination of several factors, including source and destination IP addresses, source and destination port numbers, and the transport protocol being used (such as TCP or UDP).
