# UEFI (Unified Extensible Firmware Interface) 

- A modern firmware interface for computers
- Designed to replace the older BIOS (Basic Input/Output System). 

It acts as an intermediary between a computer's operating system and its hardware. It manages the boot process and offers more advanced features than BIOS.

## Key Features
- Graphical Interface: Unlike the text-based BIOS interface, UEFI often includes a graphical user interface (GUI), making it easier to navigate and configure settings.
- Larger Boot Drives: UEFI supports booting from drives larger than 2.2 TB, which is a limitation in BIOS.
- Secure Boot: UEFI includes a security feature called Secure Boot, which helps protect the system from malware by ensuring that only trusted software can be executed during the boot process.
- Faster Boot Times: UEFI can provide faster boot times compared to BIOS due to more efficient handling of the initialization process.
- Support for Modern Hardware: UEFI supports more advanced hardware configurations, including newer processors, GPUs, and storage devices.
- Compatibility: While UEFI is designed to replace BIOS, it typically includes a Compatibility Support Module (CSM) that allows it to emulate BIOS, enabling it to boot older operating systems that are not UEFI-aware.
- Extensibility: UEFI is modular and extensible, allowing manufacturers to add additional features or support for new hardware without significant changes to the core firmware.
